# V1.5.1 Living Executive OS

> 状态更新（2026-09-06）：V1.5.1 的工程验收记录保留，但其主要呼吸态视觉已由 V1.5.2 的 Executive Pulse Core 与 Global AI Orb 取代。V1.5.2 最终用户视觉验收仍待确认。

## 1. Ambient Architecture

本轮范围仅限老板端 `/dashboard`。页面以 `ExecutiveAmbientBackground` 作为 Level 0 环境层，实际 Dashboard 内容位于独立内容层；Hero、数据区、浮层分别使用更高 Surface Level，避免所有模块呈现为同一种白色卡片。

环境层只承担视觉表达，不接收指针事件，不参与业务计算，也不改变 V1.5 已有权限、AI DTO、Numeric Grounding、Token Usage 与 Rate Limit 行为。

## 2. Mesh Gradient

页面 Mesh 由 Forest、Sage、Champagne、Muted Cyan 与暖灰的低饱和径向渐变叠加，底色保持 `#F4F5F1` / `#F7F7F3`。Hero 使用独立的深 Forest Mesh、低透明数据网格和数据流线，避免大面积紫色、霓虹和赛博朋克视觉。

不同渐变层使用不同尺寸、位置和动画周期。静态底色始终存在，因此动画关闭或尚未启动时仍保持完整的视觉层级。

## 3. Living Motion

页面 Living State 分为三类：环境光场缓慢漂移、Hero 与关键 KPI 的轻微光泽呼吸、AI Online / 经营状态 / 风险状态的低频脉冲。动画周期错开，确保静置 5-10 秒可以感知变化，但不会形成同步闪烁或持续浮动卡片。

统一 Motion Tokens 管理 Ambient、Breathe、Chart、Hover、Tooltip 和 Scroll Reveal 时长。下方模块进入视口时只执行一次轻量 reveal，不使用持续 JavaScript `requestAnimationFrame`。

## 4. Chart Motion

图表明确区分 Entrance、Living 和 Interaction 三层反馈：首次进入保留 Recharts 原生绘制；现金流 Area 的填充与关键风险点保持低频呼吸；柱状图和 Donut 在悬停时突出当前数据、弱化同组数据，并通过 Tooltip 展示业务上下文。

现金流展示契约新增每日 `topReceivable`、`topPayable` 与 `riskMessage`。项目健康数据继续沿用原健康分口径，Tooltip 可使用 `contractCents`、`budgetRate`、`collectionRate`、`procurementRate`、`riskCount` 与 `reasons`，不重新计算财务指标。

## 5. Hover System

可交互 KPI 的 Hover / Focus 同步调整位移、边框亮度、阴影、图标和 Mini Bars，并显示真实经营细分，不再只显示解释性文案。Action Center 在保持稳定布局的同时揭示风险原因、金额、项目、到期日和人工建议。

展示数据由数据库与 Analytics 生成，不由 AI 编造。V1.5.1 新增的 `executiveDetails` 包含 Top Account、逾期客户摘要和欠票供应商摘要；没有资源权限时对应分组为 `null`，不得用 0 表示不可访问数据。

## 6. Drill-down

交互入口保持业务上下文：

- 现金流日期进入 `/finance-workspace?date=YYYY-MM-DD`。
- 公司资金 Donut 点击公司后切换公司范围。
- Project Health 点击进入 `/projects/[id]`。
- 应收账龄进入带 `bucket` 的 `/receivables`。
- 应付到期结构进入带 `bucket` 的 `/payables`。
- Action Item 进入对应审批、应收、供应商欠票或项目预算上下文。
- KPI 进入其授权范围内的财务、审批、应收、应付或项目台账。

## 7. Reduced Motion

`prefers-reduced-motion: reduce` 关闭 Ambient Drift、Mesh 位移、Orb Drift、Glow Breath、Flow Line、Living Chart Animation 与 Scroll Reveal。静态渐变、状态颜色、Tooltip 内容和所有 Drill-down 功能继续保留，信息不依赖动画表达。

## 8. Responsive

Desktop 保留完整 Ambient、Hero、数据流线和图表交互；Tablet 缩小环境光场并重新组织信息列；Mobile 只保留 1-2 个低成本 Light Field，关闭复杂 Grid Motion 与 Flow Lines。KPI 细分、图表入口和 Action Item 必须通过键盘或触控访问，页面不得产生横向溢出。

## 9. Performance

实现不使用 Three.js、Canvas Particle、WebGL、Shader、持续 `requestAnimationFrame` 或高频 `mousemove`。持续装饰动画限定在 `transform`、`opacity`、`background-position`、SVG `stop-opacity` 与低频 `stroke-dashoffset`；曲线阴影为静态样式，滤镜、模糊和大面积重绘保持受控。Recharts 只为数据进入和明确交互启用动画，业务数据查询继续在服务端完成。

展示查询只返回 Dashboard 所需摘要：每日最多一条 Top Receivable 和 Top Payable、一个 Top Account、逾期客户汇总与欠票供应商汇总。所有查询沿用公司范围和项目成员范围，并在资源不可访问时直接跳过。
