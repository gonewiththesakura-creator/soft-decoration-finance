# V1.5.2 Executive Pulse + Global AI Orb

## 1. Scope

本版本只升级老板首页的可感知呼吸态和全系统 AI 入口，不增加财务、采购、Excel 或 AI Tool 业务模块。旧 Topbar Copilot 入口已移除，独立 `/ai` 工作台继续保留。

## 2. Executive Pulse

Dashboard Hero 新增 `ExecutivePulseCore`，由 Ambient Glow、两层错峰 Ring、Inner Core 和状态文案组成。状态只复用既有经营规则：未来 30 天出现资金缺口时为“风险”，既有高风险优先事项存在时为“需要关注”，其余为“稳健”；没有新增经营评分。

Core 和 Ring 使用同一个 5.2 秒节奏，第二层 Ring 延迟 2.6 秒。Hero Mesh、Orb 和 Flow Line 继续作为低强度环境层，不承担主要状态表达。

## 3. Global AI Orb

`GlobalAIAssistant` 挂载在登录后的 `AppShell`，因此 Dashboard、项目、采购、财务、供应商、客户、付款、应收、应付、发票与数据迁移页面共享同一个 AI 实例。浮球使用 Deep Forest、Muted Teal、Sage 与 Muted Amber 状态色，支持 Online、Thinking、Warning 和 Error / Degraded。

浮球始终以 4.6 秒周期呼吸；Thinking 状态缩短为 3.2 秒。Hover / Focus 会固定到 1.04 放大并增强 Glow，Tooltip 同时显示服务状态和当前业务上下文。

## 4. Floating Window

桌面端为右下角 440px 非模态浮窗，最高 640px；业务页面仍可浏览和点击。移动端使用 78vh Bottom Sheet，不强制跳转 `/ai`。Header 提供最小化、进入完整 AI 工作台和关闭操作，正文继续复用既有 `AiAssistant`、Structured Response、Tool Calling 和 `requestAI` 流程。

浮窗始终 mounted。收起只改变可见状态，不卸载消息、`conversationId` 或输入草稿；客户端路由切换后旧对话继续存在，新问题使用新的 `pageContext`。

## 5. Context

`contextFromPathname` 覆盖 Dashboard、Finance Workspace、Procurement Workspace、Project、Supplier、Customer、Payment Request、Purchase Request、Purchase Order、Receivable、Payable、Payment 和 Invoice。明细页优先展示页面中的实体名称，列表页展示稳定业务标签。服务端继续白名单解析这些只读上下文字段。

## 6. Motion And Accessibility

持续主视觉限定为 Executive Pulse、Cashflow Pulse 和 Global AI Orb。普通 KPI、Action、Donut、按钮与 Card 不再持续呼吸。`prefers-reduced-motion: reduce` 会关闭 Pulse、Orb Ring、Ambient Drift 和浮窗过渡，但保留静态 Glow 与状态色。

浮球使用原生 `button`、明确的 `aria-label`、`aria-expanded` 和 `aria-controls`。展开完成后焦点进入输入框，`Esc` 收起并把焦点归还浮球；所有图标按钮均提供可访问名称。

## 7. Responsive

Desktop 浮球为 64px，距右 28px、距底 26px；Mobile 为 56px，距右和底 18px。内容区预留底部安全边距，浮窗层级高于业务页面、低于真正 Modal。390×844 实测没有页面横向溢出，Bottom Sheet 高度为 78vh。
