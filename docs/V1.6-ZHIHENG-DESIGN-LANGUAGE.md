# V1.6 ZHIHENG Design Language Reset

## 1. Scope

本版本重置项目、财务、采购和老板端的视觉语言，不改变权限、审批、资金、采购、数据迁移或 AI 工具的业务规则。交付停在 Phase C：全局视觉基础、Dashboard、Executive Pulse、Global AI Orb 与浮动对话窗完成升级，不扩展新的业务模块。

## 2. Source And Governance

根目录 `DESIGN.md` 是 ZHIHENG DESIGN SYSTEM v2.0 的唯一设计规范，`MOTION.md` 是动效规范。Agent 不得自行修改或降低两份规范中的标准；后续变更必须提交 Design System Change Proposal 并由人类批准。

设计参考来自固定版本的 `VoltAgent/awesome-design-md`，上游提交、文件哈希、许可和借鉴边界记录在 `docs/DESIGN-SOURCES.md`。参考内容已按 MIT 许可随仓库归档，便于离线审计。

## 3. Visual Foundation

- 画布使用暖矿物白与冷矿物白的极弱过渡，主体内容保持清晰、安静和可扫描。
- 导航使用 Deep Forest；激活态以克制的 Champagne 细线和轻量面高亮表达，不使用大面积发光。
- Intelligence、Technical、Living、Champagne 与四类财务语义色各自承担明确职责。
- 普通面板、表格、输入框、按钮和 Badge 统一使用 Surface Levels、细边框与轻阴影，避免所有模块都表现成白色浮卡。
- 金额、比例、日期和计数使用系统无衬线字体与 `tabular-nums`；等宽字体只用于技术 ID 和代码。

## 4. Executive Experience

老板端 Hero 采用深色 Financial Intelligence Surface。Executive Pulse 保留状态呼吸、双环扩散和技术刻线，但降低泛光与游戏感；经营状态仍来自既有规则，不新增评分。

Dashboard 的 KPI、现金流、项目健康、资金结构和风险模块按主指标、风险、预警和普通信息建立表面层级。持续动态仍只保留 Executive Pulse、Cashflow Pulse 和 Global AI Orb 三个主核心。

## 5. Global AI

全局 AI Orb 使用 Living Teal、Deep Forest 和 Champagne 技术细线，保持既有在线、思考、预警和错误状态。桌面浮窗改为平直的 Deep Intelligence Header 与矿物白工作区；移动端继续使用 78vh Bottom Sheet。对话状态、页面上下文、输入焦点、Esc 归还焦点和完整 AI 工作台跳转均保持不变。

独立 `/ai` 工作台在 1440x900 首屏内完整显示输入区，长历史记录在布局内部滚动，不再把输入区推到视口之外。

## 6. Responsive And Accessibility

1440x900、1920x1080 与 390x844 已进行浏览器实机检查。Dashboard、项目、财务、采购、供应商、客户和 AI 工作台均无页面级横向溢出；移动端业务表格继续在自身容器中滚动。

可交互控件保留可见焦点环和原生语义，颜色不作为唯一状态信号。`prefers-reduced-motion: reduce` 会关闭持续呼吸、漂移、光环、图表 living animation 和浮窗过渡，同时保留静态状态与业务信息。
